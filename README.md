# DemoBots Swift 6 Rework

Este proyecto es un rework/refactor educativo del sample code **DemoBots: Building a Cross Platform Game with SpriteKit and GameplayKit**, creado originalmente por Apple.

El objetivo de este repositorio es estudiar cómo está construido un juego 2D profesional con SpriteKit y GameplayKit, actualizar el código para Swift 6 y documentar el proceso paso a paso.

Este repositorio mantiene la licencia original de Apple incluida en el archivo `LICENSE.txt`.

## Sobre DemoBots (Original)

DemoBots es un juego 2D creado por Apple para demostrar el uso de SpriteKit y GameplayKit.

El proyecto muestra cómo implementar:

- Movimiento basado en agentes
- Sistemas de reglas y estados
- Comportamientos de inteligencia artificial
- Diseño de niveles con herramientas de Xcode

El jugador controla un robot que debe convertir enemigos en aliados dentro de un tiempo límite.


## Objetivo del proyecto

- Actualizar el sample original a Swift 6.
- Entender la arquitectura de un juego con SpriteKit.
- Aprender GameplayKit, estados, agentes, comportamientos e inteligencia de enemigos.
- Reorganizar el código aplicando buenas prácticas (Clean Architecture / MVVM donde tenga sentido).
- Documentar el proceso para otros desarrolladores que estén aprendiendo.
- Servir como base para crear juegos propios en SpriteKit.
- Acompañar el desarrollo con vídeos explicativos en YouTube.

## Qué puedes aprender aquí

- Uso de SpriteKit para juegos 2D
- GameplayKit: entidades, componentes y sistemas (ECS)
- Máquinas de estado y lógica de comportamiento
- Inteligencia básica de enemigos
- Organización de un proyecto de juego profesional

## Motivación

Aprender a desarrollar juegos con SpriteKit y GameplayKit puede resultar complejo al principio, especialmente al enfrentarse a proyectos avanzados como DemoBots.

Este repositorio nace con el objetivo de descomponer ese proceso, actualizar el código a tecnologías actuales y servir como guía práctica para entender cómo se construye un juego desde una base profesional.
